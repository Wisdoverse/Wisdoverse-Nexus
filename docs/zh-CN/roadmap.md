# 路线图

Wisdoverse Nexus 仍处于 pre-1.0 工程预览阶段，适用于开发、评估和非生产环境。
这份公开路线图说明工程优先级与验收标准，不承诺固定交付日期或稳定兼容性。

[英文路线图](../en/roadmap.md)是主版本；中文版保持相同的优先级和里程碑状态。

## 当前基础

“已有实现”表示仓库中存在代码；“已配置”表示存在工作流或部署资源。
这些状态本身不代表某次发布已通过验收。

| 领域 | 当前状态 | 仍需验证 |
| --- | --- | --- |
| 网关 | 已有房间/消息 HTTP 路由、WebSocket 认证、指标和 OpenAPI 入口 | 契约一致性和完整的客户端到网关流程 |
| 架构 | 网关领域已引入 DDD 边界，Web 应用已引入 FSD 分层 | 功能演进时持续维护领域边界和前端依赖规则 |
| 客户端与 SDK | 已有 Web、Expo 移动端、TypeScript SDK 和 Python SDK 实现 | 对齐支持的路由、载荷、认证和 WebSocket 行为 |
| CI | 已配置 Rust 检查、移动端兼容/类型/测试检查、Web/SDK/文档构建和安全检查 | 增加针对运行中网关的客户端/SDK 检查，并保留可复现结果 |
| 发布与部署 | 已配置容器/TypeScript SDK 发布工作流和 Compose/Helm 资源 | 验证发布产物、持久化、升级和恢复行为 |

相关仓库结构和验证命令参见[架构概览](../en/architecture.md)、
[测试指南](../en/guides/testing.md)和[发布流程](../en/guides/release-process.md)。

## 优先里程碑

以下里程碑均为**计划中**。仅在验收检查通过，并在公开 issue 或 PR 中关联验证证据后，
才标记为完成。优先级表示实施顺序，不代表发布日期。

### M1 / P0：核心协作流程

围绕支持的认证、房间、消息和 WebSocket 契约，对齐网关、API 文档、Web/移动端和两套 SDK。

验收标准：

- 记录并测试支持的认证流程，包括拒绝无效凭据和过期凭据。
- 使用合成数据，在运行中的网关上演示创建/列出房间、发送/接收消息，验证 WebSocket 认证和重连。
- 对照网关路由和实际提供的 OpenAPI 文档，检查客户端及 SDK 的请求/响应结构。
- 在 CI 中运行针对真实网关进程的客户端/SDK 冒烟检查；仅通过 mock 测试或构建不足以完成验收。

### M2 / P1：持久化与租户可靠性

在扩大支持的部署范围前，验证存储与隔离能力。

验收标准：

- 按文档配置持久化存储后，验证网关重启仍能恢复房间和消息数据。
- 验证 HTTP 和 WebSocket 流程观察到一致的房间/消息状态。
- 按文档中的 feature flag 和存储配置测试租户访问边界，包括拒绝跨租户请求。
- 验证数据导出/删除、备份/恢复和故障恢复路径。
- 发布可复现的 benchmark 方法及实测结果，说明环境条件和适用限制。

### M3 / P2：AI 协作示例

实现一个连接模型提供商、房间上下文和 MCP 工具调用的文档示例，明确标注实验能力。

验收标准：

- 使用合成对话和文档化的设置命令演示完整流程。
- 覆盖提供商/工具失败、超时和配置的权限边界。
- 运行时注入提供商凭据，公开示例和结果移除个人信息与私有部署细节。
- 说明支持的集成和仍处于实验阶段的集成。

## 持续维护

- 保持 `main` 可从全新 checkout 复现，并保留 Rust、移动端、Web、SDK 和文档检查。
- 持续运行依赖审计、密钥扫描和安全问题私有报告流程。
- 维护 DDD/FSD 边界，记录 breaking changes 和迁移说明。
- 保持中英文路线图的优先级和状态一致。

## 实验领域

以下领域在仓库中已有代码或设计，但接口仍在演进：

- AI 提供商与 MCP 集成
- 插件与 skills 运行时
- 会议、文档、任务和日历协作域
- 联邦部署与 A2A 设计
- 向量搜索与记忆集成

## 1.0 前的准入条件

稳定发布前，维护者应为以下项目记录验证证据：

- 完成 M1 和 M2，并明确支持的 M3 集成范围。
- 发布稳定的 HTTP/WebSocket 和 SDK 兼容策略，包括弃用期限和迁移指南。
- 明确标记实验 crate、端点和集成。
- 验证可重复执行的发布工作流及容器、SDK 产物。
- 记录部署要求、持久化、备份/恢复和升级流程。
- 在 CI 中使用运行中的网关验证客户端和 SDK 示例。

已有发布工作流和部署文档构成基础；仍需完成发布和恢复验证。

## 社区反馈

公开规划使用 GitHub：

- [Discussions](https://github.com/Wisdoverse/Wisdoverse-Nexus/discussions)：提案和设计讨论
- [Issues](https://github.com/Wisdoverse/Wisdoverse-Nexus/issues)：缺陷和范围明确的工作项

公开提案、日志、截图和 benchmark 结果使用合成或脱敏示例。发布前移除个人信息、
客户/租户标识、私有基础设施地址和凭据。里程碑 issue 应包含验收标准和验证证据。

安全问题请使用 [SECURITY.md](https://github.com/Wisdoverse/Wisdoverse-Nexus/blob/main/SECURITY.md)
中的私有报告流程。
