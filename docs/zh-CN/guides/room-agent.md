# 受治理的房间助手评估

M2 已实现显式人工调用、具名 Agent、来源消息引用、按序进度/回答事件、提供商实际用量、幂等重试和取消。当前支持默认 feature、单租户、单进程网关。英文 [配置与契约指南](../../en/guides/room-agent.md) 是详细说明的来源；[ADR-009](../../en/architecture/adr/009-governed-room-agent.md) 记录设计与限制。

本地自动验收通过 158 个案例/分组，包含版本化的 50 个合成案例各运行三次，以及独立 MCP 客户端、两个 SDK、Web/移动端 API 和控制器的真实网关联调。合成 HTTP 提供商验证传输、权限和预算，不证明真实模型的回答质量或人工试点验收。最终 PR 仍需公共 CI 证据；M2 尚不能标记为完整验收完成。

助手默认关闭。启用需要 `NEXIS_AGENT_ENABLED=true`、`OPENAI_API_BASE`、`OPENAI_DEFAULT_MODEL` 和运行时注入的 `OPENAI_API_KEY`。除回环地址外强制 HTTPS。模型须支持流式 chat completions、最终实际 token 用量与 `[DONE]`。问题和已授权消息会发送给配置的模型；前端在调用前披露这一点。日志、指标和公开证据不得包含凭证或私密内容。

房间下的 `/agents`、`/agent-runs`、运行读取/事件/取消接口与 `/mcp` 均检查当前权限。只有人工身份可调用；调用者或房间创建者可取消。同一 `clientRunId` 与相同请求在单进程一小时窗口内返回同一运行，内容不同返回 409。权限撤销后终止执行并拒绝观察，但无法收回模型已经收到的数据。

上下文最多 20 条消息、32 KiB；全局最多 4 个活跃运行、每房间 1 个；最多 60 秒、1 次只读工具调用、4,096 输出 token。另有保守的 UTF-8 字节上限及 512 事件上限。未知写工具、跨房间来源、模型请求工具、缺少用量或提前 EOF 均显式失败。回答不会自动创建共享文档或任务。

执行 `scripts/m2_smoke.sh` 前安装 `tests/smoke/m2_requirements.txt`，通过 `NEXIS_SMOKE_PYTHON` 指定 Python。`artifacts/m2/summary.json` 保存可复现的结果与摘要。真实模型烟雾测试必须显式启用并使用运行时配置；持久化、租户恢复、人工批准写操作与真实试点仍有各自的后续验收门槛。
